## 还没做的

1. **联机**（台账 `DEFERRED(Network)` 61 + `OMIT(Network)` 8）：RakNet、数据包、ServerPlayer、MultiPlayerLevel、加入游戏界面。浏览器里不能直接用 UDP，要做得改成 WebSocket，需要另立计划。**等用户决定做不做。**
2. **触屏输入**（`DEFERRED(Touch)` 2，C++ 约 1100 行）：只在手机网页上需要。
3. **统计**（`DEFERRED(Stats)` 2、`OMIT(Stats)` 1）：不影响游玩。
4. 有理由保持不移植的（理由写在代码里）：
   - 大爆炸、水花两种粒子（创建语句在 C++ 里被注释掉；还缺 `misc/explosion.png` 与基类 `WaterDropParticle`）；
   - `CreatorMode`（只在 `#ifdef CREATORMODE` 时编译）；
   - `RolledSelectionListV`（只被联机的加入游戏界面使用）；
   - 地牢 `DungeonFeature`、村庄 `TownFeature`（没有调用点）；
   - 三脚架相机拍照 `takePicture`、若干析构函数与调试代码。
