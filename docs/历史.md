## 关键决定

- **以参考 C++ 源码为唯一基准，1:1 移植**，不做“改进”。原版的怪癖照原样保留，并在文件头注明；只有 C++ 的未定义行为（越界解引用、读未初始化内存）改成安全写法，标 `ADAPTED(Safety)`。
- **数值按三档处理**（见 `docs/移植规范.md` 的 R4），只有种子到世界的链条、存档格式等要求逐位一致，用黄金样本核对。
- **启动入口与原版一致**：打开页面先是起始菜单。`startDemoWorld()` 只作为测试与场景的后门保留。
- **联机暂缓**：浏览器不能直接用 UDP，联机相关语句全部标 `DEFERRED(Network)`，等单独决定。
- **原版没启用的东西照移植但不启用**：新 AI（`useNewAi` 恒为假）、大树、`/gimmieitems`。要启用会让行为与原版不同，需要用户拍板。
- **新 AI 也在 H11 移植**：虽然原版不启用，用户决定照样移植，单测里强制开启来验证。
- **触屏输入暂缓**：只在手机网页上需要。
