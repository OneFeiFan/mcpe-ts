# nbt 包

对照：`src/nbt/*.h`、`Tag.cpp` ↔ `packages/nbt/src/*.ts`。2026-10 全量审核。存档黄金样本（nbt、leveldata、playerdata、entities、chunk 等）逐字节钉住读写，这里逐函数核对其余语义。

| 类 / 函数                                                      | 结论                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tag：构造、equals、print、setName、getName、newTag、getTagName | 一致（`PrintStream::print` 在 C++ 里是空函数）                                                                                                                                                                                                                                                                             |
| Tag.readNamedTag / writeNamedTag                               | 一致（未知类型：C++ 读完名字后返回 NULL、不读负载，TS 相同）                                                                                                                                                                                                                                                               |
| NbtIo.read / write                                             | 一致；怪癖保留：`write` 总是返回 false                                                                                                                                                                                                                                                                                     |
| ByteTag、ShortTag、IntTag、LongTag                             | 一致（构造时按 char / short / int / long long 截断）                                                                                                                                                                                                                                                                       |
| FloatTag、DoubleTag 的构造、读写、equals、copy                 | 一致（FloatTag 构造时转 float）                                                                                                                                                                                                                                                                                            |
| FloatTag.toString、DoubleTag.toString                          | **已修 N1**：C++ 是 `ss << data`（%g，6 位有效数字）。FloatTag 以前用 `String(data)` 会打印出 float 的全部 double 位数；DoubleTag 自写的格式化在进位改变指数、科学计数法去零、恰好一半时与 printf 不同。新增 `util/formatG`：在精确的二进制值上四舍六入五成双（与 glibc 相同），与 printf `%g` 的 617 个对照用例逐字符一致 |
| StringTag                                                      | 一致；怪癖保留：`len` 存的是**名字**的长度，读入后也不更新                                                                                                                                                                                                                                                                 |
| EndTag                                                         | 一致                                                                                                                                                                                                                                                                                                                       |
| ByteArrayTag                                                   | 一致；怪癖保留（已有黄金样本 G11-3）：`load` 与 `copy` 都不设置长度，读回或复制后长度为 0                                                                                                                                                                                                                                  |
| CompoundTag                                                    | 一致：按键的字节序有序写出与遍历（`std::map`）；`insert` 遇到已有的键**不覆盖**（所有 put 方法都是）；`putDouble` 的形参是 float（怪癖保留，存进去的 double 先被舍入）；取不到时 `getCompound` / `getList` 返回新建的空标签而不插入。ADAPTED：`deleteChildren` 之后 C++ 的映射里留着悬空指针，TS 直接清空                  |
| ListTag                                                        | 一致；怪癖保留：`equals` 的判断写反了（有任何一对元素相等就返回 false）。ADAPTED(Safety)：负下标与未知元素类型在 C++ 里是未定义行为，TS 分别返回 null（置错误位）与抛错；未初始化的 `type` 取 TAG_Byte                                                                                                                     |
| ListTagFloatAdder                                              | 一致                                                                                                                                                                                                                                                                                                                       |
