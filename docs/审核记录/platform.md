# platform 包

对照：`src/platform/*` ↔ `packages/platform/src/*.ts`。2026-10 全量审核。

| 文件 / 函数                                                                  | 结论                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| time.getTimeS                                                                | **已修 P1**：C++ 返回 float（Linux 版：`(float)(秒差) + 微秒 / 1e6f`），TS 以前返回 double。改成 float 后，长时间运行时计时的粒度与原版相同（运行 1 小时约 0.24 毫秒，1 天约 8 毫秒），依赖它的 `Timer` 等行为也一致 |
| time.getTimeMs                                                               | **已修 P1**：`(int)(getTimeS() * 1000.0f)`，float 乘法后截断                                                                                                                                                         |
| time.getRawTimeS、getEpochTimeS                                              | 一致（ADAPTED(Web)：取 `Date.now()`）                                                                                                                                                                                |
| time.sleepMs                                                                 | ADAPTED(Web)：浏览器里不能阻塞，返回 Promise                                                                                                                                                                         |
| Stopwatch（start / stop / stopContinue / 取值 / reset / printEvery / print） | **已修 P2**：累加按 float 做（C++ 字段是 float）；未初始化的 `_last` 取 0。`print` 的 `%.3f` 等用 `toFixed`（只影响日志末位）                                                                                        |
| StopwatchHandler.print                                                       | **已修 P3**：C++ 的 `std::map` 按键有序打印，JS `Map` 是插入顺序，改为先排序                                                                                                                                         |
| StopwatchNLast                                                               | **已修 P2**：数组与累加改成 float                                                                                                                                                                                    |
| SwStartStopper、SwStopper                                                    | ADAPTED：C++ 靠析构函数，TS 用 `Symbol.dispose`                                                                                                                                                                      |
| Keyboard                                                                     | 一致（45 个键码、`getKeyName` 的 43 个名字逐个相同，TAB 与 LEFT_CTRL 两边都返回 "Unknown"）；**已修 P4**：`feed` 的键码是 `unsigned char`，按低 8 位存                                                               |
| Mouse（MouseAction、MouseDevice、Mouse）                                     | 一致（DELTA_NOTSET、首次移动标记、滚轮状态在 reset 时清零）；**已修 P5**：按钮状态是 `char`（有符号，滚轮的 -1 以前会变成 255），坐标与增量是 `short`、动作与指针 id 是 `char`，构造时按类型截断                     |
| Multitouch                                                                   | 一致（含 `_clampPointerId` 对负数原样返回的怪癖）；补上文件头，删掉一句遗留的“请根据实际路径调整”注释                                                                                                                |
| log                                                                          | ADAPTED(Web)：printf 换成浏览器控制台，按级别加前缀                                                                                                                                                                  |
| fs/CFile、fs/VirtualFS                                                       | NEW：替代 C 标准库的文件函数（`file.h` 与操作系统的文件系统）。语义按 `fopen` / `fread` / `fwrite` / `fseek` 写（越过末尾写入补 0 等），性能问题已在审核第五节修过                                                   |
| CThread、HttpClient、PngLoader、audio/SoundSystem*                           | 不移植：线程（单线程浏览器）、皮肤下载（联机）、PNG 解码（浏览器自带）、声音（client 包里的 Web Audio 后端替代 OpenAL）                                                                                              |
